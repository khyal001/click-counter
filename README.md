# 🔢 عداد الضغطات الإلكتروني

موقع عداد إلكتروني بسيط يحسب عدد الضغطات مع كل ضغطة.

## المزايا
- زر كبير يحتل نصف الشاشة مناسب للجوال
- زر تصفير يحفظ القراءة في السجل قبل التصفير
- سجل لآخر العدات مع التاريخ والوقت
- حذف سجل واحد أو حذف الكل
- حفظ تلقائي في المتصفح (localStorage)

## النشر
الموقع صفحة واحدة `index.html` ويعمل مباشرة عبر GitHub Pages بدون أي بناء.

الرابط بعد النشر:
`https://<username>.github.io/<repo>/`
